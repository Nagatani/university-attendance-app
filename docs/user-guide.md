## 画面の構成

アプリには 4 つの画面があります。タブレットでは左側のメニュー、スマートフォン（画面幅 720dp 未満）では下部のナビゲーションバーで切り替えます。

| 画面 | 主な用途 |
| :--- | :--- |
| 講義・講義回管理 | 講義と講義回の作成・削除、講義回ごとの出席一覧、手動登録、CSV 出力 |
| 出席受付モード | 学生証のタッチを受け付ける全画面表示 |
| データ出力・履歴 | CSV の保存先設定、全出席データの検索・削除・書き出し |
| MIFARE 鍵・読取設定 | 学生証の読み取り設定、USB リーダーの管理、カード診断、管理者 PIN |

画面上部には、USB リーダーと本体 NFC の状態が表示されます。

| 表示 | 意味 |
| :--- | :--- |
| USB リーダー: <機種名>（緑） | 接続済みで読み取り可能 |
| USB: 権限待ち（橙） | Android の USB 接続許可ダイアログに応答してください |
| USB リーダー: 未接続 / エラー | タップすると再検索します |
| 本体 NFC: 待機中 | 本体 NFC で読み取り可能 |
| 本体 NFC: OFF | Android の設定で NFC をオンにしてください |
| 本体 NFC: 非搭載 | 外付け USB リーダーを使ってください |

## 初期設定

初回起動時には、動作確認用のサンプル講義（INFO-101 情報工学概論、MATH-204 線形代数学演習）が作成されます。不要であれば削除してください。削除後に再作成されることはありません。

### 1. 学生証の読み取り設定をする

自校の学生証で、どのセクター・ブロックに学籍番号が入っているか、どの鍵で読めるかを設定します。
大学の情報システム部門などから、次の情報を入手してください。

- 学籍番号が格納されているセクター番号とブロック番号
- そのセクターの認証鍵（Key A または Key B、16 進数 12 桁）
- 学籍番号の格納形式（文字列 / HEX / BCD）と、16 バイト中の位置

設定方法は [カードリーダーと学生証の設定](card-reader-setup.md) を参照してください。設定後、「MIFARE 鍵・読取設定」画面で実際の学生証をかざし、正しい学籍番号が表示されることを確認します。

### 2. CSV の保存先を決める

「データ出力・履歴」画面で、ワンタップ出力の保存先を設定します。

- **標準 Download（既定）**: `Download/UniversityAttendance/` に保存されます。特別な設定は不要です
- **別のフォルダを選択 (SAF)**: 端末内の任意のフォルダや SD カードを指定できます

同じ画面で、UTF-8 BOM の付与（Excel での文字化け防止、既定でオン）と、タッチ時の効果音のオン・オフも設定できます。

### 3. 管理者 PIN を設定する（推奨）

「MIFARE 鍵・読取設定」画面の「3. 運用補助・セキュリティオプション」で、数字 8 桁までの管理者 PIN を設定できます。
設定すると、出席受付モード中の次の操作に PIN の入力が必要になります。

- 出席受付モードの終了（Android の戻る操作を含む）
- 手動入力による出席登録
- テスト読取
- CSV 出力

PIN を空欄にするとロックは無効になります。PIN の制限事項は [データの扱いとセキュリティ](security-and-privacy.md#管理者-pin) を参照してください。

## 講義と講義回を登録する

「講義・講義回管理」画面で操作します。

### 講義を登録する

1. 「新規講義」をタップします
2. 講義名（必須）、講義コード、担当教員名、曜日時限・教室を入力します
   - 講義コードを空欄にすると `COURSE-xxxx` が自動で付きます
   - 講義コードは CSV のファイル名にも使われるため、英数字で付けることをおすすめします
3. 「第 1 回〜第 15 回の講義回を同時に自動作成する」にチェックすると、今日から 1 週間おきの日付で 15 回分の講義回が作られます
4. 「登録する」をタップします

### 講義回を追加する

- **全 15 回を一括作成**: 第 1 回〜第 15 回のうち、まだない回を追加します（実施日は今日から 1 週間おき）
- **講義回を追加**: 回番号、タイトル、実施日（`YYYY-MM-DD`）を指定して 1 回分を追加します

同じ講義に同じ回番号の講義回は作れません。

### 削除する

講義または講義回の削除ボタンをタップし、確認ダイアログで「削除する」を選びます。

> **注意**: 講義を削除すると、その講義のすべての講義回と出席記録も削除されます。講義回を削除すると、その回の出席記録も削除されます。元に戻せないため、必要に応じて先に CSV で書き出してください。

現在のバージョンには、登録済みの講義・講義回を編集する機能はありません。誤りがあった場合は、削除して作り直してください。

## 出席を受け付ける

1. 「講義・講義回管理」画面で講義と講義回を選びます
2. 「出席受付モードを開始（全画面）」をタップします
3. 学生に学生証を、本体の NFC アンテナ部分または外付けリーダーにかざしてもらいます

受付中は画面が常時点灯し、現在時刻が表示されます。タッチ結果は大きなバナーと効果音で知らせます。

| バナー | 意味 |
| :--- | :--- |
| 緑「出席を受け付けました」 | 出席が記録されました |
| 黄「すでに出席登録済みです」 | この講義回ではすでに出席済みです。初回の登録時刻が表示されます |
| 赤（エラー内容を表示） | 鍵の認証失敗、学籍番号の抽出失敗、通信エラーなど。もう一度ゆっくりかざしてもらってください |

バナーは約 4 秒で待機表示に戻ります。カードを置いたままにしても、1.2 秒以内の同じカードの再検知は無視されます。

> 出席が記録されるのは **出席受付モード画面を表示している間だけ** です。他の画面で学生証をかざしても、読み取った学籍番号が通知されるだけで出席は登録されません。

### テスト読取

受付画面の「テスト読取」を押すと、架空の学籍番号でタッチ時の動作を確認できます。バナーに「テスト読取成功（出席は記録されません）」と表示され、出席データには保存されません。

受付画面の「所定の場所へ CSV 出力」で、その講義回の出席データをその場で書き出すこともできます。

### 受付を終了する

「受付終了」ボタンまたは Android の戻る操作で、講義管理画面に戻ります。管理者 PIN を設定している場合は PIN の入力が必要です。

## 手動で出席を登録する

学生証を忘れた学生などのために、学籍番号を手入力して出席を登録できます。

- 講義管理画面: 講義回を選んで「手動登録」
- 出席受付モード: 「手動入力」（PIN 設定時は PIN が必要）

備考欄には「学生証忘れ」「遅刻」などを自由に記入でき、CSV の「備考」列に出力されます。登録方法は `MANUAL` として記録されます。

## 出席データを確認・削除する

- **講義回ごと**: 講義管理画面で講義回を選ぶと、その回の出席一覧（学籍番号、登録日時、登録方法、カード UID）が表示されます
- **全データ**: 「データ出力・履歴」画面で、学籍番号・講義名・講義回によるキーワード検索と、講義による絞り込みができます

どちらの画面でも、各行の削除ボタンから出席記録を 1 件ずつ削除できます（確認ダイアログあり、取り消し不可）。

## CSV で書き出す

書き出し方は 3 通りあります。

| ボタン | 動作 |
| :--- | :--- |
| 所定の場所へ CSV 出力 | 設定済みの保存先フォルダへ、ファイル名を自動で付けて保存します |
| 保存先を指定して出力 | 保存場所とファイル名を毎回選びます |
| 他アプリへ共有 | Google ドライブ、メール、ファイルアプリなどへ送ります |

書き出す範囲は、操作する画面によって変わります。

| 操作場所 | 範囲 |
| :--- | :--- |
| 講義管理画面 / 出席受付モード | 選択中の講義回 |
| データ出力・履歴画面（講義を選択） | その講義の全講義回 |
| データ出力・履歴画面（すべての講義） | 全出席データ |

列の内容やファイル名の規則は [CSV ファイルの仕様](csv-format.md) を参照してください。

## アプリを更新する

新しいバージョンの APK を [Releases](https://github.com/Nagatani/university-attendance-app/releases) からダウンロードしてインストールすると、データを保持したまま上書き更新できます。

- アンインストールしてから入れ直すと、**出席データと設定がすべて消えます**。必ず上書きインストールしてください
- 「パッケージが既存のパッケージと競合しています」と表示される場合は、署名鍵が異なる APK です。[トラブルシューティング](troubleshooting.md#アプリを上書きインストールできない) を参照してください

## 運用上の注意

- **定期的に CSV を書き出してください。** データは端末内にしかなく、クラウドバックアップの対象外です。端末の故障や紛失に備えてください
- **端末の時計を正しく合わせてください。** 出席登録日時は端末の時計とタイムゾーンで記録されます
- **効果音が鳴らない場合** は、端末の通知音量を確認してください（効果音は通知音量で鳴ります。マナーモードやおやすみモードでは鳴らないことがあります）
- **学生が受付画面から抜け出さないようにするには**、管理者 PIN に加えて Android の「アプリ固定（画面の固定）」機能の併用をおすすめします。現在のバージョンでは、ホームボタンや通知領域からの離脱はアプリ側で防げません
