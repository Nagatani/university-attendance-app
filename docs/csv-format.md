# CSV ファイルの仕様

アプリが書き出す出席データ CSV の形式です。学務システムへの取り込みや集計スクリプトを作るときの参考にしてください。

## 形式

| 項目 | 仕様 |
| :--- | :--- |
| 文字コード | UTF-8。「UTF-8 BOM 付で出力」がオン（既定）の場合は先頭に BOM（`EF BB BF`）が付く |
| 改行コード | CRLF |
| 区切り文字 | カンマ |
| 引用符 | カンマ・ダブルクォート・改行を含む値だけを `"` で囲む。値の中の `"` は `""` にする |
| ヘッダー行 | あり（1 行目） |
| 並び順 | 講義コード → 回番号 → 出席登録日時の昇順 |

## 列

| # | 列名 | 内容 | 例 |
| :--- | :--- | :--- | :--- |
| 1 | 講義コード | 講義登録時のコード | `INFO-101` |
| 2 | 講義名 | | `情報工学概論` |
| 3 | 講義回 | `第N回` の形式 | `第3回` |
| 4 | 講義回タイトル | | `ネットワークと情報セキュリティ` |
| 5 | 講義日 | 講義回の実施日（`YYYY-MM-DD`） | `2026-10-13` |
| 6 | 学籍番号 | 学生証から読み取った値、または手動入力値 | `24B10234` |
| 7 | 出席登録日時 | `yyyy-MM-dd HH:mm:ss`。端末のタイムゾーンでの時刻 | `2026-10-13 10:42:05` |
| 8 | 登録方法 | 下表を参照 | `NFC(USB)` |
| 9 | カード UID | 学生証の UID（16 進数、区切りなし）。手動登録時は空 | `04A1B2C3D4E5F6` |
| 10 | 備考 | 手動登録時に入力した備考 | `学生証忘れ` |

### 登録方法の値

| 値 | 意味 |
| :--- | :--- |
| `NFC(USB)` | 外付け USB NFC リーダーで読み取った |
| `NFC(本体)` | 本体 NFC で読み取った |
| `MANUAL` | 手動で入力した |
| `NFC(USB)-UID` / `NFC(本体)-UID` | テスト用フォールバックにより、カード UID を学籍番号として記録した |

## 数式の無効化（CSV インジェクション対策）

値が `=`、`+`、`@`、タブ、CR で始まる場合は、Excel などで数式として実行されないよう先頭に `'` を付けて出力します。
例えば手動登録の備考に `=1+1` と入力した場合、CSV には `'=1+1` と書き出されます。

## ファイル名

```text
attendance_<講義コード>_session<回番号>_<出力日時>.csv
```

| 出力範囲 | 例 |
| :--- | :--- |
| 講義回 | `attendance_INFO-101_session3_20261013_104500.csv` |
| 講義 | `attendance_INFO-101_20261013_104500.csv` |
| 全データ | `attendance_ALL_COURSES_20261013_104500.csv` |

講義コードに英数字・`_`・`-` 以外の文字が含まれる場合は `_` に置き換えられます。

## 保存先

「所定の場所へ CSV 出力」の保存先は次のとおりです。

| 設定 | 保存先 |
| :--- | :--- |
| 標準 Download（Android 10 以降） | `Download/UniversityAttendance/` |
| 標準 Download（Android 8〜9） | `Android/data/app.nagatani.dev.attendance/files/exports/`（アプリ専用フォルダ） |
| 別のフォルダを選択 | 選択したフォルダ。同じ名前のファイルがあれば上書きする |

> **注意**
> - Android 8〜9 のアプリ専用フォルダは、アプリをアンインストールすると削除されます。「保存先を指定して出力」や「他アプリへ共有」で別の場所にも保存してください
> - 選択したフォルダが削除された場合やアクセス権限が失われた場合は、通知なしに標準 Download に保存されます。出力完了メッセージに表示される保存先を確認してください

「他アプリへ共有」で作る一時ファイルはアプリのキャッシュに置かれ、1 時間以上前のものは次回の共有時に削除されます。
