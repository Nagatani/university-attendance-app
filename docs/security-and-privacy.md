# データの扱いとセキュリティ

このアプリは学籍番号（個人情報）と学生証の認証鍵を扱います。導入前に、データの保存場所と保護の範囲を確認してください。

## 端末に保存されるデータ

| データ | 保存場所 | 備考 |
| :--- | :--- | :--- |
| 講義・講義回・出席記録 | アプリ専用領域の SQLite DB（`university_attendance.db`） | 学籍番号、カード UID、登録日時、備考を含む |
| 読み取り設定（MIFARE 鍵を含む） | アプリ専用領域の SharedPreferences | **平文で保存** |
| 管理者 PIN | 同上 | **平文で保存** |
| CSV 保存先、BOM・効果音の設定 | 同上 | |
| 書き出した CSV | 選択した保存先（既定は `Download/UniversityAttendance/`） | 他のアプリからも読める場所です |

アプリ専用領域のデータは、Root 化されていない端末では他のアプリから読めません。アプリをアンインストールすると削除されます。

## バックアップと端末移行

- Android の自動バックアップ（`allowBackup`）は無効です
- Android 12 以降のクラウドバックアップと端末間データ移行からも、すべてのデータを除外しています

そのため、端末の機種変更や初期化ではデータは引き継がれません。データを残すには CSV で書き出してください。現在のバージョンには、CSV からデータを取り込む機能はありません。

## ネットワーク通信

アプリはインターネット権限を持たず、外部と通信しません。データが端末の外に出るのは、利用者が CSV を書き出したり共有したりしたときだけです。

## 管理者 PIN

管理者 PIN は、教室で学生が受付画面を操作することを防ぐための簡易的なロックです。保護されるのは出席受付モード中の次の操作だけです。

- 受付終了（戻る操作を含む）
- 手動入力
- テスト読取
- CSV 出力

次の点に注意してください。

- 「MIFARE 鍵・読取設定」画面は PIN で保護されていません。受付モード以外の画面を開ける人は、PIN を変更・解除できます
- ホームボタン、タスク切り替え、通知領域からは PIN なしでアプリを離れられます。Android の「アプリ固定（画面の固定）」機能を併用してください
- 入力の失敗回数に制限はありません
- PIN は平文で保存されます

## 運用上の推奨事項

- タブレットには画面ロック（PIN やパスワード）を設定し、管理者以外が操作できないようにする
- 書き出した CSV は、学内の規程に沿って安全な場所に保管し、端末の `Download` フォルダに残さない
- 年度末など不要になった時点で、講義を削除して出席記録を消去する
- 本番運用では「テスト用フォールバック（UID 読み取り）」をオフにする
