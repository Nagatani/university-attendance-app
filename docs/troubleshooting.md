## 学生証が読めない

まず「MIFARE 鍵・読取設定」画面を開いて学生証をかざし、表示されるエラーを確認してください（[カード診断](card-reader-setup.md#カード診断で設定を確かめる)）。

| 表示 | 原因と対処 |
| :--- | :--- |
| 何も反応しない | 本体 NFC がオフ、または非搭載です。画面上部の状態表示を確認してください。本体のアンテナ位置は機種によって異なるため、背面の上下を少しずつずらしてかざしてみてください |
| MIFARE Classic 非対応カード | 本体の NFC チップが MIFARE Classic に対応していません。外付け USB リーダーを使ってください |
| セクター認証失敗 / 鍵認証エラー | 鍵、鍵種別（A/B）、セクター番号のいずれかが違います。鍵リストと「試行順」の表示を見直してください |
| ブロック読み取り成功・文字列抽出エラー | 認証はできています。16 バイトの表示を見ながら、Offset・Length・格納形式・正規表現を調整してください |
| セクター番号範囲外 / ブロック番号範囲外 | カードの容量に対して番号が大きすぎます。1K カードはセクター 0〜15、ブロック 0〜3 です |
| カード通信エラー | 読み取り中にカードが離れました。カードを 1 秒ほど静止させてかざしてください |
| MIFARE 鍵設定エラー | 有効な鍵が 1 件もありません。鍵リストに 12 桁の 16 進数を書いてください |

## USB リーダーが認識されない

1. 画面上部の USB 表示をタップする（再検索されます）
2. 「USB: 権限待ち」と表示されたら、Android の許可ダイアログで「許可」を選ぶ
3. 許可を一度拒否した場合は、「MIFARE 鍵・読取設定」画面の「USB 再検出」をタップする（自動では再度確認しません）
4. 「検出された USB デバイス」に機器が表示されていれば、「この機器に接続」をタップする
5. 表示されない場合は、ケーブルや OTG アダプタを確認する。タブレットが USB ホスト（OTG）に対応している必要があります

読み取りが不安定になったときは、リーダーを抜き差しすると復帰することがあります。

## 出席が登録されない

- **出席受付モード画面以外では、出席は登録されません。** 講義管理画面などでかざすと、学籍番号の通知だけが表示されます
- 黄色の「すでに出席登録済みです」が出る場合は、その講義回で登録済みです。別の講義回を選んでいないか確認してください
- 「講義回が未選択です」と出る場合は、講義管理画面で講義と講義回を選んでから受付を始めてください
- 「出席記録を保存できませんでした」と出る場合は、受付中にその講義回が削除された可能性があります。講義回を確認してもう一度かざしてください

## 効果音が鳴らない

- 「データ出力・履歴」画面の「カード読取時の効果音を有効化」がオンになっているか確認してください
- 効果音は **通知音量** で鳴ります。端末の通知音量を上げ、マナーモードやおやすみモードを解除してください

## CSV が見つからない・文字化けする

- 出力完了時に画面下部へ表示されるメッセージに、実際の保存先が書かれています
- 標準設定では `Download/UniversityAttendance/` に保存されます（Android 8〜9 ではアプリ専用フォルダ）。詳しくは [CSV ファイルの仕様](csv-format.md#保存先) を参照してください
- 選択した保存先フォルダへのアクセス権限が失われると、標準 Download に保存されます。「別のフォルダを選択 (SAF)」で選び直してください
- Excel で文字化けする場合は、「UTF-8 BOM 付で出力」をオンにして出力し直してください

## アプリを上書きインストールできない

「パッケージが既存のパッケージと競合しています」などと表示されて上書きできない場合は、次のどちらかです。

- **署名鍵が違う**: インストール済みのアプリと新しい APK が、別の鍵で署名されています。配布元に確認してください（開発者向け: [リリース手順](release.md#署名鍵キーストアの管理)）
- **バージョンが古い**: インストール済みより `versionCode` が小さい APK は入れられません

アンインストールすれば新しい APK を入れられますが、**出席データと設定はすべて消えます**。先にすべての出席データを CSV で書き出してください。

## 管理者 PIN を忘れた

出席受付モードで PIN を求められて先に進めない場合は、次の手順で解除できます。

1. ホームボタンなどでアプリを離れる（アプリ固定を使っている場合は先に解除する）
2. アプリを開き直し、出席受付モード以外の画面（講義管理画面など）を表示する
3. 「MIFARE 鍵・読取設定」画面で PIN を空欄にするか、新しい PIN を設定して保存する

アプリがタスク一覧に残っていて受付画面のまま開く場合は、タスク一覧からアプリを終了してから開き直してください。
