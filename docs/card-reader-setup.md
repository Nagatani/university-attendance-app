# カードリーダーと学生証の設定

## 読み取りの仕組み

MIFARE Classic カードのメモリは「セクター」に分かれ、各セクターは 16 バイトの「ブロック」で構成されます（1K カードは 16 セクター × 4 ブロック）。
各セクターの最後のブロックは「セクタートレーラ」で、そのセクターの鍵とアクセス条件が入っています。

アプリは次の順序で学籍番号を取り出します。

1. 指定されたセクターに対して、鍵候補を順番に試して認証する
2. 認証できたら、指定ブロックの 16 バイトを読み取る
3. 16 バイトのうち指定範囲を、指定の形式（文字列 / HEX / BCD）で文字列に変換する
4. 正規表現が設定されていれば、それに合う部分だけを取り出す

## セクターとブロックを指定する

| 項目 | 説明 |
| :--- | :--- |
| 読み取りセクター番号 | 学籍番号が入っているセクター。1K カードは 0〜15、4K カードは 0〜39 |
| セクター内ブロック番号 | セクター内のブロック位置。通常は 0〜2 |

> 1K カードではブロック 3、4K カードの大きなセクター（32〜39）ではブロック 15 がセクタートレーラです。学籍番号が入っていることはないため、通常は指定しないでください。

## 認証鍵を指定する

「セクター認証鍵リスト」に、1 行に 1 件ずつ鍵を書きます。書いた鍵は上から順に試され、最初に認証できた鍵が使われます。

### 書式

| 書式 | 例 | 意味 |
| :--- | :--- | :--- |
| 12 桁 HEX のみ | `FFFFFFFFFFFF` | 全セクター共通の鍵。Key A / Key B は「優先鍵種別」の設定に従う |
| 鍵種別 : 鍵 | `B:A0A1A2A3A4A5` | 全セクター共通で、指定した鍵種別で試す |
| セクター : 鍵 | `1:A0A1A2A3A4A5` | セクター 1 専用の鍵。鍵種別は「優先鍵種別」に従う |
| セクター : 鍵種別 : 鍵 | `1:A:A0A1A2A3A4A5` | セクター 1 を Key A で認証する。鍵種別に `AB` を書くと両方試す |
| セクター : Key A : Key B | `1:A0A1A2A3A4A5:B0B1B2B3B4B5` | セクター 1 の Key A と Key B を 1 行で指定する。片方が不明なら `-` を書く |
| セクター見出し | `[Sector: 2]` | 以降の行のうちセクター指定のないものを、セクター 2 用として扱う（MIFARE Classic Tool の書式と互換） |

補足:

- 区切り文字には `:` と `,` のどちらも使えます
- `#`、`//`、`;` 以降はコメントとして無視されます
- 鍵の `0x` 接頭辞、空白、`-` は自動で除去され、小文字は大文字として扱われます
- 書式に誤りがあると、画面に行番号付きでエラーが表示されます

記述例:

```text
# 学生証の鍵（セクター 1 を Key A で認証）
1:A:A0A1A2A3A4A5

# 予備として工場出荷時の鍵も試す
FFFFFFFFFFFF
```

### 優先鍵種別と両方の試行

- **優先鍵種別（Key A 優先 / Key B 優先）**: 鍵種別を書いていない行を、どちらの鍵種別で試すかを決めます
- **「鍵種別(A/B)を省略した12桁HEX行は Key A と Key B の両方を順に自動試行する」**: オン（既定）にすると、優先鍵種別で失敗したときにもう一方の鍵種別も試します

### 試行の順序

鍵候補は次の順に試されます。画面の「試行順」欄で、実際の順序を確認できます。

1. 対象セクターを明示した鍵（例: `1:A:...`）
2. セクター指定のない共通の鍵
3. 上記それぞれの中では、工場出荷時の鍵 `FFFFFFFFFFFF` より他の鍵を先に試す

同じ鍵種別・同じ鍵の重複は自動で取り除かれます。
また、鍵リストで別のセクターを指定している場合（例: 読み取りセクターが 1 で、`2:A:...` の行がある）、そのセクターも読み取り候補として試します。

一度認証に成功したセクターと鍵は記憶され、次の学生からは最初に試されます。そのため 2 人目以降の読み取りは速くなります。

### プリセット

鍵リスト欄の下のボタンで、よく使う内容を一括入力できます。

| ボタン | 入力される内容 |
| :--- | :--- |
| 標準3鍵を一括セット | `FFFFFFFFFFFF`、`A0A1A2A3A4A5`、`D3F7D3F7D3F7`（よく使われる既定鍵） |
| セクター:A/B:鍵 書式例 | 現在のセクター番号を使った記述例 |
| 初期値 (FFFF...) のみ | `FFFFFFFFFFFF` のみ |

「貼り付け」ボタンで、クリップボードの鍵リストを貼り付けることもできます。

## 学籍番号の抽出方法を指定する

| 項目 | 説明 |
| :--- | :--- |
| 格納形式 | 下表を参照 |
| 開始バイト位置（Offset） | 16 バイト中の何バイト目から読むか（0〜15） |
| 読み取りバイト長（Length） | 何バイト読むか（1〜16）。Offset との合計が 16 を超える場合は自動で切り詰められます |
| NULL 文字や空白を自動除去する | オン（推奨）にすると、`0x00` などのパディングや前後の空白を取り除きます |
| 抽出・検証用正規表現 | 任意。指定すると、変換後の文字列からパターンに合う部分を取り出します。合わない場合はエラーになります |

### 格納形式

| 形式 | 変換方法 | 例（バイト列 → 学籍番号） |
| :--- | :--- | :--- |
| ASCII / UTF-8 文字列 | バイトを文字コードとして解釈します（最も一般的） | `32 34 42 31 30 32 33 34` → `24B10234` |
| HEX（16 進数表記） | バイトをそのまま 16 進数の文字列にします。除去オン時は末尾の `00` バイトを取り除きます | `01 23 45 67 89` → `0123456789` |
| BCD（二進化十進数） | 4 ビットずつ 10 進数の 1 桁として解釈します。除去オン時は `F` などのパディングを取り除きます | `24 10 23 4F` → `2410234` |

### 正規表現

- パターンに合った部分全体が学籍番号になります
- グループ（`( )`）があれば、1 番目のグループが学籍番号になります
- 例: `[0-9A-Za-z-]+`（英数字とハイフンだけを取り出す）、`^S(\d{8})`（先頭の `S` を除いた 8 桁の数字）

## カード診断で設定を確かめる

「MIFARE 鍵・読取設定」画面を開いたまま学生証をかざすと、**出席登録はせずに** 次の内容を表示します。

- 認証に成功したセクター・ブロックと、使われた鍵
- 読み取った 16 バイトの HEX と ASCII 表示（現在の抽出範囲は青枠で表示）
- 現在の設定で抽出される学籍番号

診断には **保存前の設定** が使われます。Offset や形式を変えながら学生証をかざし、正しい学籍番号が出たら保存してください。
学生証が手元にない場合は「サンプルデータで検証」で、架空のデータを使って抽出設定を確認できます。

> 保存せずに別の画面へ移ると、編集中の設定は破棄されます。

## 外付け USB NFC リーダー

USB CCID（PC/SC）に対応した非接触 IC カードリーダーを使えます。本体 NFC がない機種や、本体 NFC が MIFARE Classic に対応していない機種で使ってください。

動作を想定している主な機種:

- Sony PaSoRi RC-S300 / RC-S300/P / RC-S300/S（RC-S300 向けの専用制御を実装しています）
- ACS ACR122U / ACR1252U / ACR1281U
- Identiv uTrust 3700F
- HID OMNIKEY 5022 / 5427

### 接続手順

1. USB-C または OTG 変換アダプタでリーダーをタブレットに接続します
2. 「このアプリで開きますか」または USB 接続許可のダイアログが出たら「許可」します
3. 画面上部の USB 表示が緑になれば準備完了です

うまく認識されない場合は、「MIFARE 鍵・読取設定」画面の「外付け USB NFC リーダー (PC/SC CCID)」欄で次の操作ができます。

- **USB 再検出**: 接続中の USB 機器を探し直します。許可を拒否した機器にも、もう一度許可を求めます
- **この機器に接続**: 検出された機器（VID / PID 付きで表示）から、使うリーダーを選びます
- **切断**: 現在のリーダーとの接続を切ります

USB の接続許可を一度拒否すると、自動では再度求めません。「USB 再検出」をタップしてください。

## 本体 NFC

本体の NFC で MIFARE Classic を読むには、NXP 製など MIFARE Classic に対応した NFC チップが必要です。対応していない機種では、カードをかざすと「MIFARE Classic 非対応カード」と表示されます。その場合は外付け USB リーダーを使ってください。

Android の設定で NFC がオフになっていると読み取れません（画面上部に「本体 NFC: OFF」と表示されます）。

## テスト用フォールバック（UID 読み取り）

「テスト用フォールバック: MIFARE Classic 以外の NFC タグ検出時にカード UID を学籍番号として読み取る」をオンにすると、MIFARE Classic として読めないカードの UID を学籍番号の代わりに記録します。手元に学生証がないときの動作確認用です。

この方法で登録した記録は、登録方法が `NFC(本体)-UID` のように `-UID` 付きで記録されます。**本番運用ではオフにしてください。**
